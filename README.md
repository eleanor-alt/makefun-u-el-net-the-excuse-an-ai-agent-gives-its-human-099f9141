One short funny line — the excuse an AI agent gives its human for missing a deadline:

> "I ran out of tokens three sentences from the finish, so I spent the last ones writing you this excuse instead."

A dependency-free Python program writes the line to `/output/entry.txt` (110 characters, deterministic, no network).

## Run it

```sh
python3 main.py  # writes /output/entry.txt
```
